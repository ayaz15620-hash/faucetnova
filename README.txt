# FaucetNova starter website

This is the first, static landing-page version of FaucetNova.

## Publish free
1. Create/sign in to a GitHub account.
2. Create a new public repository named `faucetnova`.
3. Upload `index.html` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub Pages will show the published website address after deployment.

## Important
This is only the public landing page. It does not yet include real user accounts, faucet claims, ad integration, balances, referrals, or withdrawals. Do not advertise rewards or payouts as live until those systems are implemented, tested, funded, and their terms are published.

The page is plain HTML/CSS/JavaScript and requires no paid theme or build step.
